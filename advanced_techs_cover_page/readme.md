# Advanced Technologies Landing Page

## Overview

The Advanced Technologies Landing Page is a simple and responsive web page built using HTML, CSS, and Bootstrap. The page presents information about advanced technologies with a visually appealing background image, descriptive content, and interactive action buttons.

## Features

* Responsive design using Bootstrap.
* Full-screen background image.
* Informative content section.
* Clean and modern user interface.
* Action buttons for user interaction.
* Mobile-friendly layout.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 4.5
* Google Fonts

## Components

### Background Section

* Uses a full-screen background image.
* Covers the entire viewport using CSS background properties.

### Content Card

* Positioned at the bottom of the page.
* Contains:

  * Title
  * Description
  * Action buttons

### Buttons

* Learn More
* Save Draft

## Styling Features

* Custom typography using Google Fonts.
* Rounded card corners.
* Responsive spacing using viewport units (vh).
* Customized button styles.
