# 💻 Day 2 — Coding Cover Page

Today I built a **Coding Cover Page** using HTML and CSS!
It is a simple and clean landing page designed for a coding 
related website. 🚀

## 🛠️ What I Built
A coding themed cover page with:
- A dark coding background image
- Heading and description text
- Clean and centered layout
- Simple and attractive design


## 💡 What I Learned Today
- How to add and style background images using CSS
- How to center content on a page
- How to choose fonts that match the theme
- How to make text readable on dark backgrounds

## 😅 Challenges I Faced
- Finding the right background image URL
- Making the text visible on dark background
- Getting the layout centered properly


## ✅ How I Fixed It
- Used background-size cover and background-position center
- Added proper text color and font styling
- Used CSS margin and padding to center content
- using Bootstrap flex properties

## 🔑 Tech Used
- HTML
- CSS
- Bootstrap
