# K.L. Rahul - Cricket Player Profile

A static website showcasing the profile and achievements of Indian cricketer K.L. Rahul.

## Features

- Player bio and introduction
- Match highlights and videos
- static design for all devices
- Clean and modern layout

## Technologies

- HTML5
- CSS3


## File Descriptions

- **index.html** - Main page with player profile
- **styles.css** - Styling and layout
- **images/** - Player action shots and match images
