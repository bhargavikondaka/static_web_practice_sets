# 🌙 Sleep Music App

A responsive, two-page sleep music web app built with HTML, CSS, and Bootstrap.

---

## 📌 Project Overview

A mobile-friendly sleep music landing page that helps users discover soothing bedtime music. Features a dark night-sky themed UI with smooth page transitions.

---

## 🖥️ Pages

### Page 1 — Landing Page
- Dark moon background hero section
- App title and description
- "Night Island" music card
- **Get Started** button to navigate to Page 2

### Page 2 — Music Detail Page
- Featured music image
- Track name, description, and duration
- Related music section (Moon Clouds, Sweet Sleep)
- **Back** button to return to Page 1

## 🚀 How to Run

1. Download or clone the project folder
2. Make sure `index.html` and `index.css` are in the **same folder**
3. Open `index.html` in any browser
4. Click **Get Started** to go to Page 2
5. Click **Back** to return to Page 1
