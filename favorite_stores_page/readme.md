# 🛍️ Shop in Your Favourite Stores

A responsive mobile-style web page that displays a curated list of popular online stores with a purple-themed UI built using HTML, CSS, and Bootstrap 4.

---

## 📁 Project Structure

```
project/
├── index.html
└── index.css
```

---

## 🚀 Getting Started

### 1. Clone or Download the Project

Download or copy both `index.html` and `index.css` into the same folder.

### 2. Open in Browser

Simply open `index.html` in any modern web browser — no build tools or server required.

```bash
# Or use VS Code Live Server extension for hot reload
```

---

## 🎨 Features

- **Purple hero section** with a storefront illustration and heading
- **White card panel** listing stores with logo, name, and description
- **Stores included:** Amazon, IKEA, Bewakoof, Flipkart
- **Bree Serif** font via Google Fonts for headings
- **Bootstrap 4.5** for layout utilities (flexbox, card)
- Fully static — no JavaScript logic required

## 📌 Notes

- The page is designed for **mobile viewport** (single column layout)
- The white card panel slides up from the bottom over the purple hero section using `border-top-right-radius` and `border-top-left-radius`
- Store logos are displayed at **48×48px**
