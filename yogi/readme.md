# 🧘 Yoga Experience Platform

A responsive static website built with HTML, CSS, and Bootstrap that introduces users to different types of yoga.

---

## 📁 Project Structure

```
project/
├── index.html      # Main HTML file
├── index.css       # Custom styles
└── README.md       # Project documentation
```

---

## 🌟 Features

- **Homepage** with a yoga girl illustration and a mountain background
- **Get Started** button to navigate to the yoga types section
- **Back** button to return to the homepage
- **4 Yoga Cards** displaying different yoga types with images and descriptions
- **Responsive Design** — different background images for mobile and desktop (768px+)

---

## 🧘 Yoga Types Covered

| Yoga Type | Description |
|---|---|
| Acro Yoga | Stretches and relaxes your body, improves stamina and memory |
| Vinyasa Yoga | Builds lean muscle mass and serves as strength training |
| Hatha Yoga | Introduces beginners to main relaxation techniques and asanas |
| Kundalini Yoga | Relaxes and restores the mind and body, improving strength and flexibility |

---

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Custom styling
- **Bootstrap 4.5.2** — Responsive grid and utilities
- **Google Fonts** — Roboto and other font families
- **JavaScript** — Section toggle via `display()` function (ccbp ui kit)

---

## 🚀 How to Run

1. Download or clone the project files
2. Make sure `index.html` and `index.css` are in the same folder
3. Open `index.html` in any modern web browser
4. Click **Get Started** to explore yoga types
5. Click **Back** to return to the homepage

---

## 📌 Notes

- Internet connection required to load Google Fonts, Bootstrap CDN, and image URLs
- The `display()` function is provided by the CCBP UI Kit script included at the bottom of `index.html`
